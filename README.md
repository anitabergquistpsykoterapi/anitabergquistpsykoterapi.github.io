
# Anitas terapi



Static bilingual website for a private psychotherapy practice in Stockholm.



## Files



- `index.html` main landing page

- `styles.css` site styling

- `script.js` language toggle

- `integritet.html` privacy page



## Publish



Upload the files in this folder to any static host, for example:



- Netlify

- Vercel static site hosting

- GitHub Pages

- One.com or your web hotel's file manager



## Important before publishing



- Replace the CTNotes link with Anita's actual booking URL when available.

- Add a full street address if you want it visible on the site.

- Consider expanding the privacy text with a formal privacy policy if required by your business setup.
